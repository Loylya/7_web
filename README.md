# Черешня и немного весны

Уютная одиночная игра по мотивам образов песни: девочка-монстр, ромашки, черешня, коллекция крышек и мечта о Париже. Героиня — художественный персонаж, а не портрет реального автора.

## Играть

Откройте `index.html` в браузере: установка, сервер и библиотеки не нужны. Версия на GitHub Pages публикуется из корня ветки `main`.

- WASD или стрелки — ходить.
- E — сыграть ноту, зажечь фонарь или войти в арку.
- Пробел — разогнать туман. Восстановление: 1,5 секунды.
- Esc — выбор глав.
- На телефоне используйте экранные стрелки и кнопки. Можно одновременно идти и нажимать действие.
- Звук включается кнопкой сверху. Музыка синтезируется через Web Audio API, это новая мелодия, не запись песни.

## Цель

В каждой главе найдите четыре крышки и две ромашки, зажгите все фонари и завершите мелодию, если она есть. Затем подойдите к арке и нажмите E. В тумане сокровища недоступны: используйте дыхание ветра. Ошибка в мелодии сбрасывает только её последовательность.

Пять глав: Сад после дождя; Комната непрочитанных историй; Вишнёвый вечер; Билет в бумажный Париж; Крыши, где просыпается весна.

Завершённые главы и альбом из 20 крышек сохраняются в localStorage этого браузера. Незавершённая глава при повторном открытии начинается сначала. Игра без врагов, урона, таймера и проигрыша.

## Данные

Основные данные глав находятся в JSON-блоке `world-data` внутри `index.html`, чтобы файл работал даже без сервера. `world.json` — отдельная копия для удобного чтения и редактирования. После изменения этой копии перенесите её содержимое в JSON-блок HTML. Позиции указаны в координатах Canvas 1000 × 620.

Графика рисуется собственными SVG и Canvas-примитивами. Внешние ассеты, шрифты и сетевые запросы не используются.

## Проверено

Синтаксис JavaScript; достижимость всех объектов в пяти главах с учётом коллизий и ворот; правильные и ошибочные последовательности нот; условия выхода; наполнение альбома; повторный запуск и выбор глав.
